# Predictive-Maintenance-using-Machine-Learning
Machine Learning project for predictive maintenance using the AI4I 2020 dataset. Developed Random Forest and Logistic Regression models to predict machine failures and classify failure types for industrial maintenance.

## Project Overview

This project demonstrates how Machine Learning can be used for predictive and preventive maintenance in industrial environments.

Using the AI4I 2020 Predictive Maintenance Dataset, machine sensor data is analyzed to predict machine failures before they occur. The project also classifies the type of failure, enabling preventive maintenance and reducing unexpected downtime.

---

## Objectives

- Predict machine failure using machine learning.
- Identify the type of machine failure.
- Perform exploratory data analysis (EDA).
- Compare multiple machine learning algorithms.
- Interpret model predictions using feature importance and permutation importance.
- Recommend preventive maintenance actions.

---

## Dataset

**AI4I 2020 Predictive Maintenance Dataset**

Features include:

- Machine Type
- Air Temperature
- Process Temperature
- Rotational Speed
- Torque
- Tool Wear

Target Variables:

- Machine Failure (Binary Classification)
- Failure Type (Multi-class Classification)
